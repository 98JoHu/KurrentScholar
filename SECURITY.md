# Security policy

This project is pre-release and has no supported version yet. Do not open public issues containing
sensitive manuscripts, paths, or credentials. Before publication the maintainer must add a private
security contact and response policy. KurrentScholar performs local processing, loads only pinned
safetensors with remote code disabled, and treats document parsers as a security boundary. Keep releases
and parsing dependencies patched; verify published SHA-256 checksums.
