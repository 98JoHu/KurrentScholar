# Research methodology record

For reproducibility, record KurrentScholar/software version, repository/release checksum, recognition model
ID and exact revision, model DOI, segmentation backend/version, DPI/rotation/preprocessing, generation
parameters, processing date, document identifier/hash, and manual review status. JSON exports preserve the
available machine provenance; maintain an external methods note for archival handling and decisions.

The manuscript remains primary evidence. KurrentScholar does not modernize spelling, grammar, punctuation,
names, numbers, abbreviations, or legal vocabulary and must not infer illegible content. Researchers should
enter explicit conventions such as `[unleserlich]` or `[illegible]` and document their editorial policy.
Separate machine output from human intervention and report the extent of review.
