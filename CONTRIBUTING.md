# Contributing

Open an issue before large changes. Use Python 3.11, `uv sync --extra dev`, `uv run ruff check .`, and
`uv run pytest -m "not real_model"`. Never add archival documents without recorded reuse rights, model
weights, credentials, caches, generated installers, or benchmark claims without reproducible evidence.
Changes to confidence, model loading, project schemas, or privacy behavior require corresponding docs and tests.
